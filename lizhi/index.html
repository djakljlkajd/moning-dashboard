三个关键问题

谁先谈？
BP 先谈（不是运营先谈）——BP 是人才方负责人，运营先谈会让离职人员"只认运营"。
谁主导？
BP 主导，运营配合提供信息——离职沟通涉及薪酬 / 发展 / 劳动关系，BP 专业对口。
运营角色？
提供业务背景、配合交接，不主导沟通——运营管"事"，BP 管"人"，边界清晰。

适用对象

大店长及以上（含大店长、区经理、城市经理、区域负责人）一律算核心人员，全部适用本机制。本看板底池纳管三品牌店长职级（店长 / 练习生店长 / 零售店长 / 零售副店长），共 459 人。普通店员 / 兼职不适用，运营可自行处理。

常见问题 FAQ

Q1：运营已经和离职人员谈完了，BP 还要介入吗？

要。BP 必须补做离职面谈（真因提炼），否则离职原因无法归因，下次还会招错人。运营"先斩后奏"不影响 BP 介入的必要性，但运营"先斩后奏"本身违反约束，需考核扣分。

Q2：BP 人不在本地怎么办？

视频面谈也算，但必须在 T+24h 内完成，不得以"不在本地"为由延后。如果 BP 负责的区域跨度大，建议按区域配置 BP 对接人。

Q3：离职人员坚持只和运营谈，不愿和 BP 谈？

BP 仍需介入，哪怕只是旁听，否则离职真因无法沉淀。可以运营 + BP 一起面谈，但 BP 必须在场，且面谈记录由 BP 归档。

Q4：BP 介入后，运营还需要做什么？

三件事：① 配合提供业务背景信息；② 如果能留，配合执行挽留方案；③ 如果放行，配合做好工作交接。运营不是"甩手不管"，而是"不越位但配合"。
